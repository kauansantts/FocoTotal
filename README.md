# FocoTotal
Foco Total

Aqui você gerencia suas tarefas de uma forma organizada.

📌 Sobre o projeto

Um sistema para você gerenciar suas tarefas com niveis de prioridade e persistencia de dados.
Ele foi feito para o uso diario, ao em vez de tentar decorar tarefas na mente, ou em grupos de Whatswapp, voce tem um simples sistema que gerencia todas elas para você de forma eficaz e simples.
É um projeto de console para estudos e praticas.

🎯 Objetivos

Pratica de linguagem
Alinhar conceitos não dominantes
Controlar minhas tarefas, de uma forma mais pessoal e ligada a mim


🛠️ Tecnologias utilizadas
